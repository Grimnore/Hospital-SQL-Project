# 🏥 Hospital Data Analysis: SQL Project

A beginner SQL project analyzing hospital data using PostgreSQL.

## Database
- **DBMS:** PostgreSQL
- **Tables:** patients, doctors, departments, appointments, bills

## Files
| File | Description |
|------|-------------|
| schema.sql | Table creation scripts |
| sample_data.sql | Sample INSERT data |
| queries.sql | 10 analysis queries |

## How to Run
1. Install PostgreSQL
2. Open pgAdmin 4
3. Create a new database called `hospital_db`
4. Run `schema.sql` first
5. Run `sample_data.sql` next
6. Run any query from `queries.sql`

## Analysis Performed
- Total patient count
- Appointments per doctor
- Most common diagnoses
- Revenue analysis
- Unpaid bills tracking
- Gender & city-wise distribution
